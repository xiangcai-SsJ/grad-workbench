
# 🎓 研究生工作台

> 一个**单文件 HTML** 的研究生个人工作台：任务、学院文件、论文、科研项目，全在一个页面里。
> 无需安装、无需构建、无需服务器——**双击打开即用**。

---

## ✨ 功能总览

| 模块 | 核心能力 |
|------|----------|
| 📋 **今日与任务** | 任务管理（类型 / 优先级 / 状态 / 截止）、学习打卡、今日视图 |
| 📁 **学院文件** | 拖入即登记、自动提取正文、**全格式内置预览**、AI 深度分析、步骤转任务 |
| 📚 **论文库** | 元数据管理、**AI 学术分析**（贡献 / 方法 / 结果 / 可借鉴点）、状态跟踪 |
| 🔬 **科研项目** | 项目卡片与进度条、**AI 节点规划向导**（5 问自动生成时间线）、节点管理 |
| ☁️ **数据同步** | 本机暂存 + 云端资料库自动同步、断网补传、CSV 导出备份 |
| 📖 **使用说明** | 应用内彩色说明书，首次打开自动弹出 |

### 文件预览支持格式

`PDF` · `docx` · `doc` · `ppt` · `pptx` · `xls/xlsx` · `ods` · 图片 · 音视频 · 文本/代码

> 老式格式（doc / ppt）尽力提取文字内容，保留可读性。

### AI 能力

- **文件分析**：概要、要点、操作步骤流程、链接、时间点——步骤可一键转成任务
- **论文分析**：核心贡献 / 方法 / 主要结果 / 可借鉴点，四块结构化提炼
- **节点规划**：新建项目回答 5 个问题，AI 自动排布项目时间线，预览确认后入库

## 🚀 快速开始

### 本地使用

1. 下载 `研究生工作台_v63.html`
2. 双击用浏览器打开（推荐 Chrome / Edge）
3. 完成，所有功能本地运行

### 多设备访问（GitHub / Gitee Pages）

1. 仓库设置中开启 **Pages** 服务
2. 访问生成的网址即可，更新仓库文件后所有设备自动用上新版

### 🔑 启用 AI 功能

在应用内「设置」页配置：

| 配置项 | 说明 |
|--------|------|
| API 地址 | OpenAI 兼容接口，如 `https://api.openai.com/v1` |
| API Key | 你自己的密钥，仅保存在本机浏览器 |
| 模型 | 任意兼容模型，如 `gpt-4o-mini` |

> 🔒 **隐私说明**：AI 功能仅在你手动点击时，把对应文件内容发送到**你自己配置**的接口；本地速览层完全离线运行。

## 🗂 数据存在哪里

| 数据 | 位置 |
|------|------|
| 任务 / 节点 / 文件 / 论文记录 | 浏览器本地 + 云端资料库 |
| 上传的附件 | 浏览器 IndexedDB |
| AI 配置、主题偏好 | 浏览器 localStorage |

换设备打开同一份文件即可继续原进度；纯本地使用时数据不离开你的设备。
